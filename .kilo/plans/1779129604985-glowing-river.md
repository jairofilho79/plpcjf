# Plano: Botão "Folheto" na Playlist

## Objetivo
Adicionar um botão "Folheto" na sessão Playlist (CarouselChips) que gera uma imagem (flyer/folheto) a partir dos dados da playlist atual e abre a API de compartilhamento nativa com a imagem + URL.

## Layout do Folheto (conforme imagem de referência)
- **Moldura**: borda preta sólida de ~5px ao redor
- **Cabeçalho**: à esquerda "LOUVORES", à direita dia da semana + data (ex: "DOMINGO 17/05/2026")
- **Tabela** com 2 colunas: "NÚMERO" e "NOME DO HINO"
- **Header da tabela**: fundo cinza escuro (não muito escuro), texto preto, negrito
- **Corpo**: fundo branco, texto preto, sem negrito
- **Todos os textos em caixa alta (uppercase)**

## Etapas

### 1. Instalar dependência `html2canvas`
```bash
npm install html2canvas
```
Usado para converter o HTML do folheto em imagem PNG/JPEG no cliente.

### 2. Criar utilitário de geração do folheto
Arquivo: `src/lib/utils/folhetoUtils.js`

Funções:
- `generateFolhetoHtml(louvores, playlistName)` — gera string HTML completo com os dados
- `generateFolhetoImage(htmlString)` — renderiza HTML em elemento oculto, usa html2canvas para capturar como blob/canvas
- `shareFolheto(imageBlob, shareUrl, playlistName)` — compartilha usando Web Share API (imagem + URL)

### 3. Adicionar botão "Folheto" no CarouselChips
Arquivo: `src/lib/components/CarouselChips.svelte`

- Adicionar botão `<button>` no grupo `action-buttons-group` (entre "Em Abas" e "Expandir")
- Ícone: `FileText` do lucide-svelte
- Texto: "Folheto"
- Handler: `handleFolheto()` — chama as funções do utilitário

### 4. Fluxo do handler `handleFolheto()`
1. Coleta os louvores do `$carousel`
2. Gera nome da playlist (ou usa padrão com data)
3. Converte dados para formato da tabela (número, nome)
4. Gera HTML do folheto
5. Converte HTML → imagem (html2canvas → Blob)
6. Gera URL de compartilhamento (mesma do botão Compartilhar: `generatePlaylistShareUrl`)
7. Abre Web Share API com `files: [imageBlob]` + `url: shareUrl`
8. Fallback: download da imagem se Web Share não disponível
